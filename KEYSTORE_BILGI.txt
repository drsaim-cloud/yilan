=== CODEMAGİC KURULUM ADIMLARI ===

1. CodeMagic → Uygulamanı seç → Sol menü: "Environment variables"

2. Şu değişkenleri ekle (Secure işaretle):
   ┌─────────────────────┬──────────────────────────────────────────┐
   │ Değişken Adı        │ Değer                                    │
   ├─────────────────────┼──────────────────────────────────────────┤
   │ CM_KEYSTORE_BASE64  │ keystore-base64.txt dosyasının içeriği   │
   │ CM_KEYSTORE_PASSWORD│ yilanharf123                             │
   │ CM_KEY_ALIAS        │ yilanharf                                │
   │ CM_KEY_PASSWORD     │ yilanharf123                             │
   └─────────────────────┴──────────────────────────────────────────┘

3. keystore-base64.txt dosyasını aç, içeriğini kopyala → CM_KEYSTORE_BASE64'e yapıştır

4. Debug APK için: "android-debug" workflow → Start build (keystore gerekmez)
   Release APK için: "android-release" workflow → Start build

=== NOTLAR ===
- .keystore ve keystore-base64.txt dosyalarını güvenli saklayın
